# 希望解析器

一个 AstrBot 链接解析插件。在聊天里发送分享链接，就能查看内容卡片，并接收可用的视频或图片。平台开关、解析记录、卡片样式和配置都可以在自带的管理页面里调整。

## 功能

- **自动解析分享链接**：支持单独的链接、含链接的分享口令，以及 QQ 小程序分享卡片。
- **分享卡片**：提供多种布局与深浅主题，可调整配色、封面、正文和水印。
- **自由组合输出**：文本、卡片和富媒体可独立选择；文本只保留标题、链接和简洁播放信息。
- **抖音音乐图文**：可按需附带作品配乐，音频支持语音条或音频文件发送，语音失败后自动改发文件。
- **搜歌与点歌**：支持 QQ音乐、网易云音乐单曲链接；搜歌发送带专辑封面与编号的图片卡片，选歌后发送可用音频。
- **网页管理**：查看运行状态，手动测试链接，管理解析记录与缓存，调整全部配置。
- **登录态同步与诊断**：可选连接自建 CookieCloud；查看解析步骤并导出脱敏报告。
- **常用工具**：网页截图、Pixiv 搜索、B站扫码登录，以及按平台设置代理。
- **减少重复处理**：支持解析结果复用和同群重复链接去重。

## 支持的平台

| 平台 | 支持内容 |
| --- | --- |
| B站 | 视频、动态、直播、专栏、收藏夹 |
| 抖音、快手 | 视频、图集 |
| 微博 | 正文、视频、长文 |
| 小红书 | 图文笔记、视频笔记 |
| Twitter / X | 带图片或视频的推文 |
| AcFun | 视频 |
| NGA | 帖子 |
| GitHub | 仓库信息 |
| Pixiv | 作品链接、关键词搜索，仅全年龄内容 |
| Steam | 游戏信息、价格与折扣；配置史低数据源后可显示历史最低价 |
| 小黑盒 | 帖子图文与可获取的视频、游戏分享信息；完整内容按登录状态和平台权限获取 |
| QQ音乐、网易云音乐 | 单曲分享、搜歌与点歌 |

视频和图片是否能获取，取决于内容本身的访问权限、平台限制和当前网络。需要登录的内容可在配置页填写对应 Cookie。

## 安装与开始使用

需要 **AstrBot 4.25.3 或更新版本**。支持 **aiocqhttp / OneBot**、**QQ 官方机器人**（`qq_official`、`qq_official_webhook`）和 **Telegram**（`telegram`）。QQ 官方机器人与 Telegram 建议使用 AstrBot **4.29.3 或更新版本**，消息与富媒体能力以宿主适配器为准。

1. 在 AstrBot 的插件管理中，通过仓库地址安装本插件：

   ```text
   https://github.com/xiaoxi2760/astrbot_plugin_denia_share
   ```

2. 推荐在运行 AstrBot 的环境中安装 **ffmpeg**，用于高清视频合并和封面抽帧。未安装时，B站视频会尝试使用可直接发送的单文件，画质可能降低；无法获取时在已选文本或卡片中提示。手动安装插件时，还需安装 `requirements.txt` 中的依赖。
3. 启用插件，在聊天中发送一个支持的平台链接。
4. 打开 Dashboard 侧边栏的 **插件 WebUI → 希望解析器**，按需调整设置。

AstrBot 自带的插件配置页可直接勾选禁用的平台，用「发送内容」组合选择文本、卡片和富媒体，用「允许确认的角色」组合设置确认权限；取消全部发送内容会停止聊天链接解析。原生页也提供时长、体积、搜歌数量、去重时长、水印及历史保留等常用设置。账号登录、凭据、访问名单和高级选项在插件 WebUI 的「配置」页管理，原生页不显示这些空分组。两处设置保持同步，升级会保留原有选择。原生面板保存后，AstrBot 会重载插件。

插件默认只携带**经典界面**。**达妮娅的泡泡工坊**等自设 WebUI 在独立主题仓库维护，不随插件打包。先在经典界面的「配置 → 自设 WebUI」导入主题 ZIP，或填写主题包的 HTTPS 地址下载并安装，再到「界面设置 → WebUI 样式」选择并保存。主题仓库目前只在本地建立，尚未发布在线下载地址。

自设界面与经典界面共用插件配置和数据。已安装的主题保存在插件数据目录，插件更新后可恢复，无需每次联网下载。未安装或加载失败时自动使用经典界面，也可通过 `?ui=classic` 临时恢复。安装主题不会自动改写当前界面选择。

卡片风格跟随已保存的「WebUI 样式」：经典界面使用经典卡片，泡泡工坊使用达妮娅双形态卡片。两种风格都可选择标准、杂志、沉浸、信息流四种布局；卡片明暗主题单独设置，不受网页当前明暗影响。临时进入经典页面不会改动卡片风格。旧版「达妮娅」布局会转为标准布局，并保留原先的 WebUI 选择。

### QQ 官方机器人使用说明

- AstrBot **4.29.3 及更新版本**的 WebSocket、Webhook 接入均支持非 @ 群消息。要自动解析普通链接，请在**手机 QQ → 目标群设置 → 机器人 → 该机器人 → 机器人可获取的群聊消息范围**选择**「获取群内全部消息」**。
- Webhook 还需在 QQ 开放平台「开发 → 回调配置」勾选 **`GROUP_MESSAGE_CREATE`**；WebSocket 保持 `enable_group_c2c` 开启。保存后重启 AstrBot，详见 [AstrBot 接入说明](https://docs.astrbot.app/platform/qqofficial/webhook.html)。
- B站小程序卡片若由官方 API 提供当前卡片的 `ark_data.fields.jump_url`，插件也能识别其中的 B站链接；没有该跳转地址的卡片仍需另发文字链接。
- 图片卡片、图集、视频、语音及文件由 AstrBot 官方适配器发送。官方 Bot 默认使用「紧凑预览与源链接」：有作品源链接时，多图最多合成两页缩略预览（每页 9 张）；多段视频不逐个发送，改为提示打开原作品链接。缩略图不是原图，动态图和未展示的图片也需到源链接查看。单张图片、单个视频及音频保持原发送方式；没有可用源链接时保留逐个发送。要收到每个原文件，可在「配置 → 媒体发送 → QQ 官方机器人多媒体发送」改为「逐个发送原媒体」。合并转发只适用于 OneBot。语音条依赖宿主的 Silk 转码能力，发送失败时可在插件设置中选「语音条（失败后发送文件）」。
- 紧凑投递会标明已解析的图片或视频数量，「查看完整作品」经腾讯文档外链页打开，并附原链接供复制回退，无需创建文档或登录腾讯文档。部分客户端可能显示「继续访问」或要求复制到浏览器；过长链接保留原地址。
- 权限名单请填写**官方 API 的用户 openid / 群 openid**，不要填 QQ 号、群号或整串 UMO。可用 AstrBot 的 `/sid` 辅助查看会话标识，再核对所需的用户或群 openid；启用白名单后填错 ID 会让非管理员的解析请求被静默拦下。
- 「QQ 群主/管理员可确认」只支持 `aiocqhttp` 群事件。官方机器人请选原分享者、任何有访问权的用户或 AstrBot 管理员。当前确认方式是发送 `确认下载` 文本指令。
- 解析或下载超过 QQ 被动回复窗口后，宿主可能改用主动发送；此时需在手机 QQ 的群机器人设置中开启「机器人主动在群聊内发言」。高频发送还会受到 QQ 官方频控和内容审核影响。

### Telegram 使用说明

- 在 AstrBot 中添加并启用内置 Telegram 机器人，插件会自动识别接入平台，无需切换插件模式。支持私聊和群聊中的分享链接、文字超链接及图片说明中的链接；相册后续图片说明也会检查，已由正文处理的链接不会重复解析。
- 要在群里自动解析普通链接，需要让 Telegram 向机器人投递这些消息：在 **@BotFather → `/setprivacy` → 选择机器人 → Disable** 关闭隐私模式，再将机器人移出并重新加入群，或将机器人设为群管理员。私聊不受群隐私模式限制。详见 [Telegram 隐私模式说明](https://core.telegram.org/bots/features#privacy-mode)。
- 文本、卡片、图片、视频和音频沿用同一组输出设置。媒体通过 AstrBot 直接上传，不使用 QQ 的媒体中转和文件路径映射；音频文件以附件发送。当前图集逐条发送，不使用 OneBot 合并转发，也不合成为 Telegram 相册。
- Telegram 公共 Bot API 通常限制文件上传为 **50 MB**，图片另有 **10 MB** 及尺寸限制；本地 Bot API 的限制不同。使用公共接口时，可将插件的单文件体积上限设为 **50 MB 以下**，超限内容从原作品链接查看。具体以 [Telegram Bot API](https://core.telegram.org/bots/api#sending-files) 为准。
- 访问名单填写 Telegram 用户 ID / 群 ID（群 ID 通常带负号；论坛话题需保留 AstrBot 返回的 `#话题ID` 后缀）。「QQ 群主/管理员可确认」不适用于 Telegram，可选原分享者、任何有访问权的用户或 AstrBot 管理员。

## 管理页面

| 页面 | 可以做什么 |
| --- | --- |
| 总览 | 查看状态、切换平台开关、B站扫码登录、检查媒体发送设置 |
| 解析 | 粘贴链接预览卡片，展开截图工具或管理自定义解析器 |
| 缓存 | 搜索、预览和删除解析记录，清理缓存文件 |
| 外观 | 调整分享卡片并实时预览；展开「界面主题」可修改管理页外观 |
| 配置 | 按分类浏览或搜索设置，修改后保存 |

卡片外观决定聊天中发出的图片样式，界面主题只影响管理页面。大部分配置保存后立即生效；需要重载的项目会在说明中标注。

分享卡片的昵称、标题和正文支持常用 emoji；颜色取决于系统字体，没有可用系统字体时会使用随包附带的单色字体。复杂组合在部分环境中会降级显示为基本表情或文字，肤色变化也可能不保留。

分享记录中的「源文件」可下载该记录已缓存的视频、音频或图片；一个文件直接下载，多个文件自动打包为 ZIP。「卡片原图」单独下载渲染后的卡片。未下载或已清理的源文件无法下载；部分文件已清理时，仅打包仍可用的文件，并提示缺失数量。

新版「卡片工坊」集中显示常用选项，文字细节、渲染开关、渐变和界面外观按需展开，预览可点击「放大」。账号操作集中在「平台与账号」；「设置」默认显示分类目录，搜索时直接展开匹配项。

工坊采用等高的设置与预览面板，展开更多选项时在设置区内滚动，保存按钮始终可用。首页预览把说明和操作移到卡片两侧，让卡片占用更多画面，也可放大查看。

「外观」和「配置 → 卡片外观」均可切换 **B站 AI 总结**，两处设置同步，默认关闭。开启后在标准、杂志、信息流卡片中显示可用总结；沉浸式保持原样。需要有效的 B站登录状态，暂无总结时自动隐藏。

## 命令

日常解析直接发送链接即可。以下命令用于额外操作：

| 命令 | 用途 |
| --- | --- |
| `/shot <网址>` | 截取网页图片 |
| `/pixiv <关键词>` | 搜索 Pixiv 全年龄作品 |
| `/bili_login` | B站扫码登录，管理员可用 |
| `/bili_check` | 检查 B站登录状态 |
| `点歌 [QQ/网易云] <关键词>` | 显示本插件的搜歌卡片，不指定平台时同时搜索两家 |
| `听1` / `听 1` | 发送自己最近一次列表的第 1 首音频，默认 5 分钟内有效 |
| `确认下载` / `确认下载 <编号>` | 确认模式下下载并发送源媒体；有多个待确认分享时填写卡片中的编号 |
| `/denia_status` | 查看运行状态，管理员可用 |
| `/denia_clear` | 清空解析缓存，管理员可用 |

链接解析、搜歌点歌、网页截图和 Pixiv 搜索受配置中的黑白名单控制。「点歌 歌名」只发搜索卡片，「听N」只发送选中音频，不再附带普通解析卡片；发送音频需要开启「富媒体」，并按所选策略发送语音条、音频文件，或语音失败后转文件。普通分享链接仍遵循文本、卡片与富媒体选项。旧默认命令会自动迁移，自定义命令保留；命令别名、默认音乐平台和结果数量可在「配置 → 音乐设置」调整。

## 常用配置

最常动的几项：

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| `DISABLED_PLATFORMS` | 空 | 禁用不需要的平台，也可直接在总览页切换 |
| 输出模式 | 卡片 + 富媒体 | 文本、卡片、富媒体可任意组合；全部关闭时停止聊天链接解析 |
| `VIDEO_DURATION_MAXIMUM` / `VIDEO_SIZE_MAXIMUM_MB` | 480 秒 / 100 MB | 视频与音频下载上限；超限原因显示在已选文本或卡片中 |
| `SEND_ERROR_MESSAGES` | 关闭 | 解析失败时是否在聊天里提示 |
| `BILI_QUALITY` / `BILI_CODEC` | 1080P / H.264 优先 | B站下载画质与编码偏好，实际画质取决于账号和视频权限 |
| `PROXY` | 空 | 代理地址，配合各平台与网页截图的代理开关使用 |
| `CACHE_TTL_HOURS` | 24 小时 | 媒体缓存保留时长，设为 0 关闭自动清理 |
| `RESULT_CACHE_TTL_SECONDS` | 600 秒 | 期间重复发送同一链接时复用解析结果，仍会发送卡片 |
| `DUPLICATE_LINK_WINDOW_SECONDS` | 60 秒 | 同群短时间重复链接不再反复发送卡片；设为 0 关闭，私聊不受影响 |

需要 B站登录时，可在「配置 → 账号凭据 → B站」扫码，也可使用总览页入口。Steam 地区与史低数据源、平台凭据、截图后端和访问权限等设置，也都在配置页。

在「配置 → 账号凭据」统一管理 B站、小红书、小黑盒、Pixiv、QQ音乐、网易云音乐的 Cookie 和 GitHub Token。可粘贴原文、请求头、复制为 cURL 的内容，或导入 JSON、cookies.txt；GitHub 使用个人访问令牌。点击「导入并保存」立即生效，也可检查、替换或清除。已保存内容不会回显；「已配置」表示保存完成，是否仍有效要以检查结果为准。遇到网络故障、验证页或无法识别的响应，会显示「状态未知」并保留凭据。

B站与音乐账号可在同处扫码登录，QQ音乐另提供登录态刷新。网易云扫码受平台限制时可改用浏览器 Cookie 导入。登录后按账号权限获取歌曲，会员身份不保证所有歌曲均可下载；仅有试听权限时会提示试听，取不到音频时保留歌曲信息并说明原因。

小黑盒需要登录的帖子，可在「配置 → 账号凭据 → 小黑盒」导入浏览器 Cookie；保存完成不代表登录有效，实际以解析结果为准。平台仍要求验证时，请先在网页完成验证。接口只提供摘要或部分游戏资料时，卡片会标明内容不完整。

在「配置 → 输出与投递」选择发送内容。卡片需要同时勾选「卡片」并开启「启用卡片渲染」，不会影响文本和富媒体。仅选文本时不下载媒体，仅选卡片时不下载视频本体。管理页手动预览不受聊天输出选项影响。

「输出模式 → 确认下载」可将下载时机改为 **先确认再下载**：先按所选输出展示作品，再单独发送一条确认文字，包含可取得的清晰度、大小、有效期和确认编号。回复 `确认下载` 后才下载源媒体，完成后自动发送。大小无法提前取得时会标为未知，估算值会注明。默认仍为自动下载；确认模式需开启富媒体，确认文字不受普通文本输出开关影响，也不会塞进卡片。卡片发送失败时仍可通过这条文字确认。

默认仅原分享者可确认，也可组合允许任何有访问权的用户、QQ群主/管理员、AstrBot 管理员；全部关闭则无人可确认。待确认分享默认保留 5 分钟，过期后重新分享即可。确认只改变下载时机，**日常大小、时长限制和 2GB 硬上限均保留**。点歌后的「听N」仍直接发送选中音频。

**抖音图文配乐**默认关闭，需要时在「输出模式」开启「发送图文配乐」，并勾选「富媒体」。同处可选择「音频发送方式」，共三种策略：语音条、音频文件或「语音条（失败后发送文件）」，默认仍为语音条。第三种策略优先发送语音，失败或超时时再尝试一次文件；语音成功后不追加文件。接口返回成功但客户端未收到的情况无法检测，超时兜底可能使语音和文件同时送达。普通视频不会额外重复发送背景音乐。语音条的转码能力取决于 AstrBot 和协议端；音频文件保留原格式，分容器部署时同样需要可达的中转地址、共享目录或宿主的路径映射。

**合并转发**（仅 OneBot 可用，默认不聚合）：想让一批图片或视频合并成一条消息时，在「配置 → 输出与投递 → 合并转发」选择「全部聚合」，或选「按条件聚合」并设定图片、视频与总节点的数量阈值；任一阈值命中才会合并，把某个阈值设为 0 表示这一项不触发。语音条与音频文件仍各自独立发送，简短文字和卡片保持不变。QQ 官方机器人使用上面的独立紧凑投递设置；其他不支持合并转发的平台维持逐条直发。

**代理设置**：先填写地址，再开启需要使用它的平台。新安装时各开关默认关闭，升级会保留旧代理设置。关闭插件代理开关后，运行环境的代理设置仍可能生效。Docker 中的 `127.0.0.1` 指向容器自身，代理地址应填写容器能访问的位置。

## 常见问题

### Docker 部署后，图片能发，视频发不出去

AstrBot 和 NapCat 等协议端分容器运行时，协议端可能读不到 AstrBot 下载的视频文件。在「配置 → 输出与投递 → 媒体发送」中选择一种方式：

- **媒体中转**：启用媒体中转，并填写协议端可以访问的 AstrBot 回调地址，例如同一 Docker 网络中的 `http://astrbot:6185`。协议端需要能访问这个地址。
- **共享目录**：让两个容器把宿主机上的同一个目录挂载到相同的容器内绝对路径，再将该路径填入共享缓存目录。

配置后可在总览页检查当前生效的发送方式和目录。回调地址不可达或共享目录无效时，需要先修正部署配置。

### B站需要登录吗

普通视频可在未登录时尝试解析。需要更高画质时，可在「配置 → 账号凭据 → B站」或总览页扫码登录；最终可用的画质和内容由账号权限决定。

B站依赖不可用或视频取流失败时，会尝试备用解析。备用模式仅支持 BV / av 视频，不支持动态、直播、收藏夹和专栏。

### 想添加其他平台

将自定义解析器的 `.py` 文件放入插件数据目录下的 `custom_parsers/`，然后在「解析 → 解析器扩展」中点击「重新加载」。目录中会自动生成使用说明和模板，页面也会显示加载状态。

### CookieCloud 与解析诊断

在「配置 → 平台接入 → CookieCloud」填写自建服务地址、用户密钥和加密密码，选择同步平台并保存，再点击「立即同步」。支持 B站、小红书、Pixiv、网易云音乐、QQ音乐和小黑盒；GitHub Token 继续单独管理。可参考 [CookieCloud 官方说明](https://github.com/easychen/CookieCloud)配置浏览器扩展和自建服务。

默认保留手动登录态；需要替换时勾选本次替换。自动同步默认关闭，开启后只更新未配置或仍由 CookieCloud 管理的登录态，最短间隔为 5 分钟。密码仅在机器人本地解密；同步不会让已经失效的浏览器登录态自动恢复。

「解析 → 解析诊断」展示最近 100 次聊天或网页处理的步骤，支持导出不含原始链接、账号信息和凭据的 JSON 报告。记录仅保存在内存，重启后清空；宿主未提供发送回执时会标为待确认。

自定义解析器会以插件权限运行，请只使用可信代码。
