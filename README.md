# 希望解析器

一个 AstrBot 链接解析插件。在群聊或私聊里发送分享链接、口令或小程序卡片，机器人会生成一张内容卡片，并把里面的视频、图集或音频发出来。平台开关、卡片样式、账号登录和缓存管理都可以在自带的网页后台里调整。

## ✨ 主要功能

- **自动解析链接**：识别纯链接、带链接的分享口令、QQ 小程序卡片，以及聊天中的音乐分享卡。
- **搜歌与点歌**：发送 `点歌 歌名` 生成带封面的选歌卡，回复 `听1` 发送对应音频；OneBot 下可接入自己的签名服务，额外发送可点击的音乐卡片。
- **卡片与主题**：内置标准、杂志、沉浸、信息流 4 种卡片排版与深浅配色，支持安装达妮娅、莉莉角色主题包，也可开启 B站 AI 视频总结。
- **按需组合输出**：文本、卡片、富媒体（视频 / 图集 / 音频）可独立开关；解析抖音图文时可按需附带作品配乐。
- **减少刷屏与大文件消耗**：支持同群重复链接去重、短时间结果复用、先确认再下载，OneBot 下还支持将多图和视频打包为合并转发。
- **网页后台与工具**：在线预览卡片、扫码登录、管理缓存、查看解析诊断；附带 `/shot` 网页截图和 `/pixiv` 搜图命令。

## 🌐 支持的平台

| 平台 | 支持内容 |
| --- | --- |
| B站 | 视频、动态、直播、专栏、收藏夹（登录后可获取更高画质与 AI 总结；主依赖不可用时自动走 BV/av 备用解析） |
| 抖音、快手 | 视频、图集（抖音图文可选附带背景音乐） |
| 小红书、微博 | 图文笔记、视频、微博长文 |
| Twitter / X | 公开帖文的文字、图片与视频（支持移动端分享与镜像链接） |
| YouTube | 公开视频、Shorts（支持预览与有声 MP4 下载）、社区图文帖子、直播预览 |
| QQ音乐、网易云音乐 | 单曲链接、QQ 聊天单曲分享卡、关键词搜歌与点歌 |
| Steam、小黑盒 | Steam 游戏价格与折扣（配置数据源后可显示史低）；小黑盒帖子图文、视频与游戏分享 |
| Pixiv、AcFun、NGA、GitHub | Pixiv 全年龄作品与搜图、AcFun 视频、NGA 帖子、GitHub 仓库信息 |

视频、原图和完整音频能否获取，取决于内容本身的访问权限、网络环境和账号登录状态。需要登录的平台可在插件后台扫码或导入 Cookie。

## 🚀 安装与使用

需要 **AstrBot 4.25.3 或更新版本**。支持 **OneBot (aiocqhttp / NapCat 等)**、**QQ 官方机器人** 与 **Telegram**（后两者建议使用 AstrBot **4.29.3 或更新版本**）。

1. 在 AstrBot 的「插件管理」中通过仓库地址安装（手动安装需在 Python 环境安装 `requirements.txt` 中的依赖）：
   ```text
   https://github.com/xiaoxi2760/astrbot_plugin_denia_share
   ```
2. 建议在运行环境中安装 **ffmpeg**，用于 B站与 YouTube 的高清音视频合并及视频封面抽帧。未安装时，B站会自动尝试发送单文件画质。
3. 启用插件，在聊天中发送一条支持平台的分享链接即可触发解析。
4. 打开 AstrBot 侧边栏的 **插件 WebUI → 希望解析器** 进入管理页面（常用开关也可在 AstrBot 原生插件配置页修改，两边保持同步）。

### 🎨 更换主题皮肤

插件默认使用经典界面，另可前往 **[达妮娅分享主题库](https://github.com/xiaoxi2760/denia-share-themes)** 下载「达妮娅的泡泡工坊」或「莉莉的梦境花园」主题包。  
在插件后台的「配置 → 自设 WebUI」导入主题 ZIP（或填写下载地址），再到「界面设置 → WebUI 样式」切换并保存，管理页面与聊天中的分享卡片都会换上所选外观。如果主题页面加载异常，在网址末尾加上 `?ui=classic` 可切回经典界面。

## 💬 命令

日常解析直接发链接即可。以下命令用于点歌、工具与日常维护（受黑白名单控制）：

| 命令 | 用途 |
| --- | --- |
| `点歌 [QQ/网易云] <关键词>` | 发送带专辑封面与编号的选歌卡片；不指定平台时同时搜索两家 |
| `听1` / `听 1` | 发送自己最近一次选歌列表的第 1 首音频（默认 5 分钟内有效，需开启富媒体） |
| `确认下载` / `确认下载 <编号>` | 开启「确认下载」时，回复此命令下载并发送源媒体 |
| `/shot <网址>` | 截取网页长图 |
| `/pixiv <关键词>` | 搜索 Pixiv 全年龄作品 |
| `/bili_login` / `/bili_check` | B站扫码登录（管理员可用）/ 检查登录状态 |
| `/denia_status` / `/denia_clear` | 查看运行状态 / 清空解析缓存（管理员可用） |

## 💡 常用功能说明

插件后台分为 **总览、解析、缓存、外观、配置** 五个页面，大部分设置保存后立即生效：

- **账号登录与 CookieCloud**：在「配置 → 账号凭据」中，B站和 QQ 音乐可直接扫码登录（QQ 音乐支持刷新登录态与会员曲目权限检查）；网易云音乐、小红书、小黑盒、Pixiv 支持粘贴 Cookie、请求头、cURL 或导入文件；GitHub 填写个人访问令牌。若自建了 [CookieCloud](https://github.com/easychen/CookieCloud)，可在「平台接入 → CookieCloud」填写地址与密钥同步登录态。
- **先确认再下载**：在「输出与投递 → 确认下载」开启后，遇到链接会先发送卡片与文件大小提示，由分享者（或有权限的用户/管理员）回复 `确认下载` 后再下载视频。
- **音频发送与音乐签名卡**：点歌或发送抖音图文配乐时，音频支持**语音条**、**音频文件**或**语音条（失败后发送文件）**。OneBot 下在「配置 → 音乐设置」填写签名服务地址后，还会在发歌时额外发送可点击的 QQ 音乐或网易云音乐卡片。
- **OneBot 合并转发**：在「输出与投递 → 合并转发」开启后，可将文本、卡片、多图和视频打包进同一条合并转发消息（超大或超出节点上限时自动分批，协议端拒绝时退回逐条发送）。
- **下载缓存原件与卡片调整**：在「缓存」页可将历史记录中已缓存的视频、图集下载到本地（多文件自动打包为 ZIP）；在「外观」页可调整卡片配色与排版并实时预览。

## ❓ 平台接入与常见问题

### 1. Docker 部署后，图片能发，视频或音频发不出去
AstrBot 与 NapCat 等协议端分容器运行时，协议端可能读不到 AstrBot 容器内下载的文件。可在「配置 → 输出与投递 → 媒体发送」中选择一种方式：
- **媒体中转**：开启媒体中转，填写协议端可访问的 AstrBot 地址（如同一 Docker 网络下的 `http://astrbot:6185`）。
- **共享目录**：将宿主机同一目录挂载到两个容器内相同的绝对路径，并填入「共享缓存目录」。

### 2. QQ 官方机器人接入注意事项
- 要在群里免 @ 自动解析，需在**手机 QQ → 群设置 → 机器人 → 对应机器人 → 机器人可获取的群聊消息范围**中选择**「获取群内全部消息」**，并开启「机器人主动在群聊内发言」。
- Webhook 接入需在 QQ 开放平台勾选 `GROUP_MESSAGE_CREATE`（[接入说明](https://docs.astrbot.app/platform/qqofficial/webhook.html)）；WebSocket 接入保持 `enable_group_c2c` 开启，保存后重启 AstrBot。
- 多图默认合成为九宫格预览，并附带腾讯文档「查看完整作品」入口与原链接；如需逐张接收，可在「配置 → 媒体发送」中改为「逐个发送原媒体」。黑白名单填写 `openid`（可用 `/sid` 查看）。

### 3. Telegram (TG) 群聊发链接没反应
- 将机器人设为群管理员，或在 `@BotFather` 中发送 `/setprivacy` 选中机器人并点击 `Disable`，再将机器人移出群重新加入（[隐私模式说明](https://core.telegram.org/bots/features#privacy-mode)）。
- 使用 Telegram 公共 Bot API 时，单文件上传通常上限为 **50 MB**，普通图片上限为 **10 MB**。黑白名单填写用户或群 ID（保留群 ID 的负号及论坛话题的 `#话题ID` 后缀）。

### 4. 解析排障与扩展开发
- **解析诊断**：在「解析 → 解析诊断」可查看最近 100 次解析的步骤耗时，并导出不含链接与凭据的脱敏 JSON 报告。
- **自定义解析器与主题**：将 `.py` 文件放入插件数据目录的 `custom_parsers/`，在「解析 → 解析器扩展」点击重新加载即可（目录内会自动生成模板与说明）；自定义 WebUI 主题使用包含 `theme.json` 与 `webui/` 的标准 ZIP 格式。请仅运行来源可信的代码。
